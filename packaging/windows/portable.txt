Pluma portable mode

While this file sits next to pluma.exe, Pluma keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the PlumaData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Pluma with its
settings. The first time PlumaData is created, any settings already in
%APPDATA%\Pluma are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Pluma loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Pluma) instead.
If PlumaData can't be written (for example on a read-only drive), Pluma logs a
warning and uses %APPDATA%\Pluma instead.
